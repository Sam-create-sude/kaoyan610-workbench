如何申请这两个 Key（图文步骤 + 花费说明）
① DeepSeek Key —— 负责「回答问题」
  1. 浏览器打开 platform.deepseek.com，用手机号注册并登录
  2. 左侧菜单点 API Keys（密钥）
  3. 点右上角 创建 API Key，随便起个名字 → 确定
  4. 立刻复制那串以 sk- 开头的字符（只显示这一次，关掉就再也看不到）
  5. 粘贴到上面第一个输入框
花费：新用户有免费额度（约 14 元），用完按 token 计费，一个论点大约 1～2 分钱。绑定银行卡或微信/支付宝充值更方便。
② 硅基流动 Key —— 负责「查找资料」
  1. 浏览器打开 cloud.siliconflow.cn，手机号注册并登录
  2. 完成实名认证（这一步必须，否则用不了）
  3. 领免费额度（页面上通常有领券入口，bge-m3 向量模型长期免费）
  4. 左侧菜单点 API 密钥 → 新建密钥 → 复制那串 sk- 字符
  5. 粘贴到上面第二个输入框
花费：注册就有赠送额度，本工作台用的向量模型 bge-m3 是免费的，不额外扣费。
怎么确认自己没填错：两个 Key 长度不一样——sk- 加上 DeepSeek 是 35 个字符、硅基流动是 51 个字符。保存时如果长度对不上，页面会提示你。
填完之后：点「保存」→ 这个页面会记住你的 Key，同一个浏览器下次打开就不用再填（换浏览器或换设备才需要重填）。

四个板块怎么用

提示：你用的是管理员的 Key，本账号不参与付费，所有功能直接可用。
① 对话问答 问具体知识点
直接提问，比如「设计与环境里关于全生命周期的原话是什么」。 回答只依据你的资料，并标注出处主题——蓝色是你的老师资料， 橙色是公开延伸资料（需自行核对）。
资料里没有的内容它会直说没有，不会编。
② 主题整理 批量出论点
21 个主题做成按钮，点一下它会读完该主题全部资料，整理出 8-9 个 「论点＋痛点＋阐述＋案例」，可一键下载为 md。
块数少于 10 的主题标成橙色，说明资料偏薄，整理出的论点可能不够用。
③ 论点扩写 按你给的论点展开
你自己想好一个论点（写成「短句A，短句B」最好），填进去点「开始扩写」。 它会先在资料库里找依据，再从「为什么这个论点是对的」和「基于这个论点要怎么做」 两个角度写阐述，并配一个具体案例。
每段带字数徽章：绿色达标可直背，橙色偏长偏短可点「再来一版」。
一次贴多行会逐个展开。它不会改你的论点；资料里没有依据时会直说没有。
④ 答题自测 出题并批改
选一个主题点「出题」，它会出一道浙工大 610 论述大题风格的题（100 分那道）， 但不直接给答案。你在下面输入框写答案提交，它会对照资料逐条批改： 哪些要点答到了、哪些漏了、论据够不够，最后给一个改进框架。
关于付费：使用前需一次性支付 ￥20，对应当前这个 API Key。 同一个 Key 只收一次，换浏览器/换设备/重新打开都不再收； 只有你主动更换 API Key 时才需要再付。
关于额度：用的是你自己的 API Key，API 费用由平台直接从你的账户扣， 不是从 20 元里出——20 元是本工作台的使用费。
关于隐私：Key 只存在你这台设备的浏览器里，服务器不保存、不记录。
